# jianing_name - 个人官网

一个简洁、现代的个人网站。

## 快速开始

直接在浏览器中打开 `index.html`：

```bash
open index.html
```

或使用本地服务器：

```bash
npx serve .
```

## 部署

推荐部署到 Vercel：

```bash
npm i -g vercel
vercel
```

## 自定义

编辑以下文件来更新内容：

- `index.html` - 修改页面结构
- `style.css` - 修改样式
- `script.js` - 添加交互逻辑

## 技术栈

- HTML5
- CSS3 (原生，无框架)
- JavaScript (原生)
